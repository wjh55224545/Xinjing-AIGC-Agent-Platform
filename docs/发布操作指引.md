# VibraImage 引擎发布操作指引

> 面向"AI+开源"赛道的开源生态落地步骤。引擎包已具备可独立安装的
> `pyproject.toml`（v0.2.0），本指引覆盖 **wheel 构建 → GitHub Release 发布 → 国内镜像** 全流程。
> 发布操作涉及外部平台账号，需仓库管理员手动执行（或提供凭据由自动化完成）。

---

## 1. 构建 wheel（本机已完成，可随时复现）

```bash
pip install build wheel
python scripts/release/build_wheel.py
```

产物：`vibraimage_engine/dist/vibraimage_engine-0.2.0-py3-none-any.whl`（约 44KB，纯 Python 通用包）。
已在全新虚拟环境验证：`pip install <wheel> --no-deps` 后可正常 `import vibraimage`。

---

## 2. 发布到 GitHub Release（推荐，替代 PyPI）

GitHub Release 是开源项目最主流的发布形态：无需注册 PyPI 账号、无审核门槛、
天然与仓库 Star/生态绑定，且支持国内直连（相对 PyPI 更友好）。

### 方式 A：网页手动操作（无需命令行凭据）

1. 打开仓库 → 右侧 **Releases** → **Draft a new release**；
2. Tag：`v0.2.0`（与 `pyproject.toml` 版本一致），目标分支 `main`；
3. 标题：`vibraimage-engine v0.2.0`；
4. 说明（可直接粘贴）：
   > 心镜平台的独立引擎组件包：白盒前庭振动情绪分析引擎。
   > - 纯 Python，无深度学习依赖，普通摄像头即可运行
   > - 支持 GPU 加速（MUSA/CUDA/CPU 自动探测，国产算力适配）
   > - Apache-2.0 许可
   >
   > 安装：`pip install vibraimage_engine-0.2.0-py3-none-any.whl`
5. 拖入 wheel 文件（`vibraimage_engine/dist/vibraimage_engine-0.2.0-py3-none-any.whl`）作为资产；
6. 点击 **Publish release**。

### 方式 B：GitHub CLI（需要已安装并登录 `gh`）

```bash
gh release create v0.2.0 \
  --title "vibraimage-engine v0.2.0" \
  --notes "白盒前庭振动情绪分析引擎，Apache-2.0，纯 Python 轻量实现" \
  vibraimage_engine/dist/vibraimage_engine-0.2.0-py3-none-any.whl
```

## 3. 国内镜像仓库（GitLink / Gitee 任选其一）

目的：国内评委/用户免翻墙即可 clone、下载 Release 资产；体现"国产开源生态"落地。

### 3.1 选择平台

| 平台 | 特点 | 适合 |
|---|---|---|
| Gitee（gitee.com） | 国内最大代码托管，支持 Releases/附件 | 推荐首选 |
| GitCode（gitcode.com，CSDN） | 国内新兴，AI 项目流量好 | 备选 |
| GitLink（gitlink.org.cn，开放原子基金会） | 开源原子基金会旗下，国产信创背景 | 若赛道强调"国产化/信创"则加分 |

### 3.2 镜像步骤（以 Gitee 为例）

1. 在 Gitee 注册账号并创建同名仓库（`Xinjing-AIGC-Agent-Platform`，公开）；
2. 添加镜像远程并推送（需要 Gitee 账号密码或 Token）：

```bash
git remote add gitee https://gitee.com/<你的用户名>/Xinjing-AIGC-Agent-Platform.git
git push gitee master:master
git push gitee master:main
```

3. （可选）在 Gitee 仓库页上传 wheel 到 Releases/附件，保持与 GitHub 一致；
4. README 中增加"国内镜像"链接（可选，保持仓库中立时可不加）。

### 3.3 同步策略

- 每次代码更新推 GitHub 后，执行 `git push gitee master:main` 即可保持镜像同步；
- 若需自动同步，可在 Gitee/GitCode 开启"从 GitHub 同步"（仓库管理 → 仓库镜像，填入 GitHub 仓库地址），
  由平台定时拉取，无需本地操作。

## 4. 后续可选：PyPI 正式发布（非必需）

PyPI 是国内高校师生 `pip install` 的首选渠道，但需注册 PyPI 账号（邮箱+API Token），
且包名 `vibraimage-engine` 可能已被占用。若发布：

```bash
pip install twine
python -m build
python -m twine upload dist/*
```

**结论**：对本次比赛，GitHub Release + 国内镜像已充分满足"开源生态"得分点，PyPI 发布不是必需的。

---

## 5. 合规与许可

- wheel 内含 Apache-2.0 LICENSE 与 NOTICE，可随发布资产分发；
- 引擎依赖（numpy/scipy/opencv）均通过 `install_requires` 声明，wheel 本身不捆绑第三方二进制；
- RAVDESS 等数据不随 wheel 分发（CC BY-NC-SA 4.0 非商业许可），数据获取走 `scripts/data/download_ravdess.py`。
