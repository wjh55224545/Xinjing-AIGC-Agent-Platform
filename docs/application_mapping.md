# 应用场景 · 功能模块 · 量化证据 映射

> 本文件客观描述平台面向的应用场景、对应的功能模块与已验证的量化证据，
> 用于快速理解"某个需求由平台的哪个部分解决、依据是什么"。
> 所有验证均基于**合成被试数据**（`is_synthetic=True`），与真实样本严格隔离，
> 仅用于方法验证、算法对比与流程演示，不冒充真实测量结果。

## 一、应用场景总览

| 场景 | 目标用户 | 核心需求 | 对应模块 |
|---|---|---|---|
| 校园心理健康筛查 | 学校心理教师 / 辅导员 | 批量快速初筛，识别风险学生 | 心理量表、风险分级筛查、预警面板 |
| 心理评估辅助 | 心理咨询师 | 多模态客观评估，辅助访谈判断 | 情绪监测、多模态融合、AIGC 报告 |
| 心理课堂演示 / 教学 | 心理学教师 / 学生 | 经典实验演示、测量原理教学 | 经典心理学实验、虚拟被试、VibraImage 教学 |
| 测评方法研究 | 研究人员 | 算法验证、量表等价性、消融对比 | 消融脚本、等价性脚本、合成数据引擎 |

## 二、场景 → 功能 → 证据 明细

### 场景 1：校园心理健康筛查

| 功能模块 | 关键入口 | 量化证据 |
|---|---|---|
| 标准化量表自评（8 种） | `GET /api/scales` | SAS/SDS/SCL-90/PSS-10/PANAS/PHQ-9/GAD-7/BFI-10 |
| 焦虑抑郁风险分级 | `POST /api/risk/assess` | 四级风险（low/moderate/high/extreme）+ 自杀意念筛查（PHQ-9 Q9） |
| 预警面板 | `GET /api/alerts` | 自动风险上报与预警分派 |

**筛查流程**：学生完成 PHQ-9/GAD-7 → 系统计算风险等级 → Q9 阳性立即触发高危标志 → 预警面板通知教师。

### 场景 2：心理评估辅助

| 功能模块 | 关键入口 | 量化证据 |
|---|---|---|
| 实时情绪监测 | `POST /api/vibraimage/analyze` | E1-E12 前庭参数 + 面部 7 类情绪 |
| 实时双模态融合（面部+前庭） | `POST /api/fusion/two-modal` | 置信度自适应加权（熵/方差），相对单模态面部 +3.4% |
| 三模态 D-S 证据融合 | `POST /api/fusion/three-modal` | 含未知焦点、冲突复核；相对单模态最佳 +2.4% |
| AIGC 评估报告 | `POST /api/aigc/report` | 多智能体协作生成结构化报告 |

### 场景 3：心理课堂演示 / 教学

| 功能模块 | 关键入口 | 量化证据 |
|---|---|---|
| 经典实验（Stroop/Flanker/Go-NoGo/IAT） | `GET /api/experiments/*/trials` | 4 个经典范式，均含文献依据与自动解释 |
| 虚拟被试（18 种剖面） | `POST /api/virtual-subjects/auto-diagnose` | 18 剖面自动诊断，量表+情绪与真值一致 15/18（83%） |
| VibraImage 测量教学 | `GET /api/vibraimage/norms` | 个体 vs 常模（N=10,266）Z 分对照 |

### 场景 4：测评方法研究

| 功能模块 | 关键入口 | 量化证据 |
|---|---|---|
| 合成数据引擎 | `POST /api/virtual-subjects/generate` | 参数化生成，隐藏真值，可复现（seed） |
| 融合策略消融 | `python scripts/ablation/fusion_ablation_v2.py` | 单/双/三模态 + 实时加权 + 旧固定权重完整对比 |
| 自适应测验等价性 | `python scripts/ablation/cat_equivalence.py` | 7题 vs 20题：θ 相关 r=0.92、省题 65%、Kappa=0.77 |
| 情绪预测评估 | `python scripts/ablation/emotion_forecast_eval.py` | MAE 降 27.3%、点异常召回 99.8%、漂移检出 100% |

## 三、数据与验证说明

- **数据来源**：全部为合成被试（`is_synthetic=True`），不涉及真实学生个人信息。
- **验证方式**：全量测试 155 项（`python -m pytest tests/`）+ 独立评估脚本（`scripts/ablation/`）。
- **可复现性**：所有随机实验均支持 `--seed` 参数，结果可复现。
- **伦理边界**：平台定位为**心理健康评估辅助工具**，不替代专业诊断；风险预警结果需专业人员复核。
