# 对照实验 E4：情绪预测与异常检测验证

- 数据：**合成时序 N=200**（is_synthetic=True，与真实样本隔离），seed=42
- 预测任务：前 20 步历史 → 预测后 10 步情绪得分
- 异常任务：每条时序注入 2 个点异常 + 1 段漂移，评估检出能力

## 预测准确率

| 方法 | MAE |
|---|---|
| 线性趋势预测 | **0.0419** |
| 恒定基线（最后值） | 0.0576 |

线性趋势预测相比恒定基线 MAE 降低 **27.3%**。

## 异常检测

| 指标 | 数值 |
|---|---|
| 点异常召回率 | **99.8%** |
| 点异常精确率 | **72.4%** |
| 点异常误报率 | 27.5% |
| 漂移检出率 | **100.0%** |

## 结论

- 预测：线性趋势预测 MAE=0.0419，相比恒定基线提升 27.3%，
  能有效外推情绪趋势（含周期波动）。
- 点异常：召回率 100%、精确率 72%，
  滑动窗口 Z-score 能有效检出情绪突变。
- 漂移异常：CUSUM 累积和检出率 100%，能识别持续情绪偏移。
- 教学意义：从「只记录情绪」升级为「可预测、可预警」，
  解决「监测滞后、无法及时发现情绪恶化」痛点。
- ⚠️ 合成数据仅用于方法验证与教学演示，不冒充真实样本。
