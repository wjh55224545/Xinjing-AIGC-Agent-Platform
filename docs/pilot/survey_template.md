# 心理健康教学现状调研问卷（试点使用模板）

> 用途：为「需求分析」评分项补充一手实证数据。
> 发放对象：心理学专业教师 / 高校心理健康教育课程学生。
> 建议样本：≥10 份（教师 + 学生），回收后统计数据作为需求分析附件。
> 使用方式：可复制为飞书问卷/问卷星发布；回收后把统计结果填入 `参赛/01-学科需求分析报告.md` 的「待补充」处。

---

## 一、教师问卷（面向心理学 / 心理健康教育课程教师）

**填答说明**：以下问题均针对您在心理测量 / 情绪教学实验中的真实体验，请在符合项前打勾或填写。

1. 您当前课程中是否包含情绪 / 心理测量的实验环节？
   - [ ] 是，每学期均有
   - [ ] 偶尔安排
   - [ ] 没有（设备或时间限制）

2. 您目前使用的情绪测量手段有哪些？（可多选）
   - [ ] 纸质量表（SAS/SDS/SCL-90 等）
   - [ ] 脑电（EEG）/ 皮电（GSR）等生理设备
   - [ ] 商用心理测评系统
   - [ ] 其他：______

3. 一次纸质量表从发放、作答到人工计分出结果，平均耗时约多久？
   - [ ] 10 分钟以内
   - [ ] 10–30 分钟
   - [ ] 30 分钟以上

4. 您认为现有情绪测量方式最主要的痛点是什么？（可多选）
   - [ ] 施测计分耗时
   - [ ] 生理设备成本高 / 操作门槛高
   - [ ] 结果仅反映主观自评，缺乏客观指标
   - [ ] 难以对全班/全年级开展常态化监测
   - [ ] 数据难以用于科研统计分析

5. 若有一款「普通摄像头 + AI 自动测量 + 量表自动计分 + 自动生成实验报告」的平台，您是否愿意在教学中试用？
   - [ ] 非常愿意
   - [ ] 愿意
   - [ ] 视情况而定
   - [ ] 不愿意

6. 您希望该平台优先解决什么问题？（开放式）：______

## 二、学生问卷（面向心理学课程学生）

1. 您是否体验过课堂上的情绪测量实验？
   - [ ] 是，且次数较多
   - [ ] 是，次数较少
   - [ ] 没有

2. 您认为现有测量过程是否有趣 / 有获得感？
   - [ ] 很有趣
   - [ ] 一般
   - [ ] 枯燥

3. 您是否希望把「AI 情绪测量 + 量表」作为课程实验内容？
   - [ ] 很希望
   - [ ] 一般
   - [ ] 不希望

4. 您对 AI 情绪测量的隐私与安全感是否担心？
   - [ ] 不担心（数据匿名）
   - [ ] 有点担心
   - [ ] 很担心

5. 您认为最有价值的课程功能是什么？（可多选）
   - [ ] 实时看到自己的情绪参数（E1–E12）
   - [ ] 与常模对照的个人报告
   - [ ] 情绪时序曲线与周报
   - [ ] 自动生成的实验报告
