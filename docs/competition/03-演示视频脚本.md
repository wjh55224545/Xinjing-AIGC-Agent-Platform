## 分镜细节

### 段 1：开场·问题（0:00–0:30）

- 画面：黑场打字逐行出现三句话："情绪测量仪器昂贵""量表计分依赖人工""实验被试难以招募" → 渐入平台仪表盘。
- 旁白：心理学专业做评估与实验教学，长期受三件事困扰：客观情绪测量依赖昂贵的生理仪器；经典量表施测计分全靠手工；真实被试数据隐私敏感、难以获取。心镜用开源 AI 把这三件事变成普通摄像头就能完成的闭环。

### 段 2：方案·架构（0:30–1:00）

- 画面：展示 README 系统架构图，依次高亮感知层→融合层→应用层。
- 旁白：心镜是面向心理学专业的智能工具平台——感知层采集面部、前庭振动与量表；融合层做多模态证据融合与自适应测验；应用层生成评估、预警与教学闭环。全栈 Apache-2.0 开源，190+ 项测试守护，GitHub CI 持续集成。

### 段 3：功能 1·量表+CAT（1:00–1:40）

- 画面：进入心理量表页，选 SAS → 作答 3–4 题 → 提交 → 展示自动计分、标准分、分级；再切到 CAT 模式，展示"已答 7 题，推荐结束"。
- 旁白：八种标准化量表开箱即用，自动计分、自动分级。更关键的是基于 IRT+GRM 的自适应测验——按最大信息量逐题推送，平均只需全量表三到四成的题量，能力估计与全量表的相关达 0.92，高风险判定一致性 0.77。

### 段 4：功能 2·情绪测量（1:40–2:30）

- 画面：上传一段含人脸的视频 → 展示分析进度 → E1–E12 参数表与曲线、K 值、效价/唤醒度结果。
- 旁白：情绪测量走的是自研白盒 VibraImage 引擎——基于公开专著公式从零实现，头部微振动经帧差分与频率分析得到 E1–E12 十二个情绪参数，每个参数都有明确心理含义，K 值对照万人常模。不需要脑电、皮电，普通摄像头即可，还完成了国产 GPU 适配，端到端加速 14 倍。

### 段 5：功能 3·融合（2:30–3:00）

- 画面：打开实时融合面板展示面部/前庭/融合三栏与置信度；再展示 /fusion/three-modal 端点 JSON 输出。
- 旁白：单一模态在真实光照下会误判，心镜用两种融合兜底：实时情绪识别走面部+前庭双模态置信度自适应加权，不一致时自动标记复核；完整评估走三模态 D-S 证据融合，含未知焦点与冲突检测。消融实验显示，融合相对最佳单模态把一致率从 79% 提到 81.4%。

### 段 6：功能 4·虚拟被试（3:00–3:40）

- 画面：虚拟被试页选择剖面（如"中度焦虑"）→ 一键生成完整作答与参数 → 展示隐藏真值 → 切到诊断校准面板看灵敏度/特异度。
- 旁白：针对被试难招募的痛点，心镜内置 18 种典型心理剖面的虚拟被试引擎——参数化生成完整作答，隐藏真值，可自动批改，还能做"算法体检"，批量评估诊断的灵敏度、特异度与一致率。所有虚拟数据严格隔离，不碰真实隐私。

### 段 7：验证·测试与 CI（3:40–4:10）

- 画面：终端执行 `python -m pytest tests/ -v`，滚动显示通过；切到 GitHub Actions 页面展示绿勾 badge；再展示性能基准输出。
- 旁白：190 多项自动化测试覆盖量表、自适应测验、证据融合、虚拟被试与 API，全部通过；每次提交 CI 自动跑全量测试。性能上，API 端点平均响应小于 10 毫秒，并发 10 吞吐超过 700 请求每秒。

### 段 8：结尾·开放成果（4:10–4:30）

- 画面：GitHub 仓库首页（Apache-2.0 badge、CI badge、README）→ 展示安装三步（clone、pip install、python run_backend.py）→ 二维码。
- 旁白：心镜以 Apache-2.0 完整开源，主项目与白盒引擎双仓库，下载即可本地运行；面向心理学专业师生与研究者开放复用。欢迎体验、提 Issue 或参与共建——让 AI 真正成为心理学科教学与科研的"CT 机"与"陪练教练"。
