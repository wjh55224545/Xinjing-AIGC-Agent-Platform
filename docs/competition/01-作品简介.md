# 作品简介（≤300 字，用于报名系统）

**作品名称**：心镜 MindMirror——面向心理学专业的 AI 心理评估与教学实验平台

**作品简介**（草稿，共 298 字）：

心镜 MindMirror 是面向心理学专业的智能工具平台，核心能力为心理评估、情绪分析与实验教学，而非教学管理工具。平台自研白盒 VibraImage 前庭振动引擎（E1–E12 情绪参数 + K 值常模对照），实现非接触、可解释的客观情绪测量；融合八种标准化量表自动计分、IRT+GRM 自适应测验（省题 65%、θ 相关 r=0.92）与三模态 D-S 证据融合（面部+前庭+量表，消融提升至 81.4%），形成"量表高效施测、情绪多维融合、风险分级预警"的评估闭环。虚拟被试合成数据引擎内置 18 种心理剖面，破解真实数据隐私难获取、实验教学被试难招募两大痛点。全栈 Apache-2.0 开源、230+ 项自动化测试通过、GitHub CI 持续集成，支持国产 GPU 与国产大模型，普通摄像头即可部署；引擎、GPU 适配层、通用 ReAct 框架均独立成可复用组件，具备强复用价值与可验证效果。
