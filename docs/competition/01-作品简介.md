# 作品简介（≤300 字，用于报名系统）

**作品名称**：心镜 MindMirror——面向心理学专业的 AI 心理评估与教学实验平台

**作品简介**（草稿，共 297 字，最终以报名系统计数为准）：

心镜 MindMirror 是面向心理学专业的智能工具平台，覆盖心理评估、情绪分析与实验教学。自研白盒 VibraImage 前庭振动引擎（E1–E12 情绪参数 + K 值常模）实现非接触客观情绪测量；融合八种量表自动计分、IRT+GRM 自适应测验（省题 65%、r=0.92）与三模态 D-S 证据融合（面部+前庭+量表，消融提升至 81.4%），形成量表施测、多维融合、风险预警评估闭环；虚拟被试引擎内置 18 种心理剖面，破解真实数据难获取、被试难招募难题。全栈 Apache-2.0 开源、250+ 项自动化测试、GitHub CI 集成，支持国产 GPU 与大模型；引擎、GPU 适配层、通用 ReAct 框架均独立为可复用组件。
