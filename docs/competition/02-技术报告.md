## 一、作品概述

### 1.1 背景与问题

心理学专业的教学、评估与实验教学长期面临四类现实问题：

1. **情绪测量实验实训门槛高**：传统客观情绪测量依赖脑电（EEG）、皮肤电（GSR）、眼动等生理仪器，设备昂贵、操作专业性强、便携性差，普通院校心理学实验教学难以大规模配备；
2. **心理量表施测计分依赖人工**：经典标准化量表（SAS、SDS、SCL-90 等）的施测、回收、原始分计算、标准分换算与分级判定大量依赖手工，效率低、易出错，教学中难以即时演示"作答→计分→解释"全流程；
3. **单一模态情绪识别可信度低**：面部表情识别在真实光照、角度、遮挡下鲁棒性有限；而基于头部微振动的前庭-情感反射（Vestibular-Emotional Reflex, VER）理论提供了不依赖光照的客观路径，但其工程化实现在国内教学科研场景中缺乏开源、白盒、可复现的工具；
4. **实验教学被试与真实数据难获取**：真实学生数据隐私敏感、获取周期长，心理测量学与实验心理学课程缺乏可重复的实训数据源。

### 1.2 目标、参赛方向与作品形态

**目标**：构建面向心理学专业的智能工具平台——以**客观生理信号（面部+前庭振动）与心理量表的融合**替代单一主观判断，以**IRT 自适应测验**提升量表施测效率，以**虚拟被试合成数据**破解被试与数据获取难题，支撑心理学专业在心理评估、情绪分析与实验教学三大环节的教学、科研与实训。

**参赛方向**：方向一「开源赋能的 AI 应用创新」——基于开源模型、开源软件、开源数据构建面向真实教育科研场景的智能体应用与专业工具平台。

**作品形态**：Web 应用 + 多智能体系统 + 可独立复用的白盒开源引擎（VibraImage）。

### 1.3 核心亮点

1. **自研白盒 VibraImage 前庭振动识别引擎（工程化开源）**：基于公开专著公式（Minkin, 2020）从零实现 E1–E12 白盒情绪参数 + K 值心理偏离度指标，每个参数有明确物理与心理含义；引擎独立打包（`vibraimage_engine/`，pyproject.toml 可 `pip install`），附独立测试与文档，作为可复用开源组件发布；完成国产 GPU（沐曦 MUSA）适配，全流水线端到端加速；
2. **三模态 D-S 证据融合 + 实时双模态置信度加权**：面部 + 前庭 + 量表经 Dempster-Shafer 证据理论融合（含未知焦点 Ω、置信度折扣、冲突检测），消融实验验证融合相对最佳单模态提升至 **81.4%**；实时情绪识别采用面部+前庭双模态置信度自适应加权，带模态一致性复核；
3. **IRT+GRM 自适应测验（CAT）**：分级响应模型直接建模多级评分，最大信息量逐题推送，仅需全量表 **30–40% 题量**，等价性验证 θ 相关 **r=0.92**、高风险一致性 **Kappa=0.77**、省题率 **65%**；
4. **虚拟被试合成数据引擎**：内置 **18 种典型心理剖面**，参数化生成完整量表作答与 E1–E12 参数（隐藏真值、is_virtual 隔离），为诊断算法提供可复现验证数据，同时支撑教学演示与算法校准；
5. **完整开源成果**：主项目 Apache-2.0 开源、GitHub Actions CI 持续集成、190+ 项自动化测试通过，普通摄像头即可部署，国产化全栈适配。

## 二、需求分析与总体方案

### 2.1 需求分析

| 目标用户 | 核心需求 | 现有做法 | 主要痛点 | 优先级 |
|---|---|---|---|---|
| 心理学专业教师 | 量表施测/计分/解释教学演示；客观情绪测量实验 | 手工计分、昂贵生理仪器 | 门槛高、难即时演示、设备不足 | ★★★ |
| 心理学专业学生 | 量表实操、情绪测量实验、被试获取 | 课本+模拟数据 | 重理论轻实操、被试难招募 | ★★★ |
| 心理测评/科研人员 | 批量计分、多模态交叉验证、可复现数据 | 人工汇总、单一模态 | 效率低、结果难验证 | ★★ |
| 心理筛查使用者 | 风险分级筛查、预警 | 纸质问卷+人工汇总 | 覆盖面有限、缺乏质控 | ★★ |

（依据：公开文献与高校教学实践，来源见附录参考文献；团队已梳理六类二十项痛点，详见 docs 需求分析。）

### 2.2 总体方案

平台采用三层架构（见 README 系统架构图）：

- **感知层**：面部情绪识别（OpenCV）+ VibraImage 前庭振动分析（E1–E12 参数）+ 八种心理量表
- **融合层**：实时双模态置信度加权融合（面部+前庭）+ 三模态 D-S 证据融合（面部+前庭+量表/CAT）+ IRT 自适应测验 + 情绪预测与异常检测
- **应用层**：Vue3 前端（13 个功能页面）+ 多智能体 AIGC + 虚拟被试合成数据 + 风险分级筛查 + 预警干预闭环

**核心流程**：量表作答/视频采集 → 感知层提取特征 → 融合层多模态证据融合与自适应测验 → 应用层生成个体评估、风险分级、AIGC 报告与预警。

### 2.3 可行性与成本

- **算力**：CPU 可完整运行（自动降级），GPU（MUSA/CUDA）可选加速——普通 PC 即可演示；
- **软件**：全开源（FastAPI/Vue/OpenCV/Ultralytics 等），无商业许可成本；
- **数据**：内置八套标准化量表题库 + 18 剖面虚拟被试生成器 + 10,266 人常模，开箱即用，无需真实学生数据；
- **周期**：学生团队可完成，全程 git 提交历史可追溯。

## 四、设计与实现过程

### 4.1 核心功能与流程

| 功能 | 输入 | 输出 | 关键流程 |
|---|---|---|---|
| VibraImage 引擎 | 视频/实时摄像头 | E1–E12 参数 + K 值 | 人脸检测→帧差分→频率分析→参数计算 |
| 双模态实时融合 | 视频 | 融合情绪标签+置信度+一致性标记 | 面部熵置信度 + 前庭窗口方差置信度加权 |
| 三模态 D-S 融合 | 视频+量表作答 | 各焦点 BPA+融合结果 | D-S 合成规则 + 未知焦点 Ω + 折扣 |
| CAT 自适应测验 | 量表作答 | 能力 θ+风险等级 | GRM 最大信息量选题 + EAP 估计 |
| 虚拟被试 | 剖面类型/seed | 完整作答+隐藏真值 | 参数化生成 + is_virtual 隔离 |
| 情绪预测 | 历史序列 | 预测值+95%CI+异常标记 | 线性趋势/Z-score/CUSUM |
| AIGC 报告 | 评估数据 | 日报/干预方案/沟通函 | 5 智能体 ReAct + LLM/模板降级 |

### 4.2 关键实现

1. **VibraImage 白盒引擎（独立开源包）**：E1–E12 每个参数有明确物理含义（如 E1 攻击性、E2 压力、E3 紧张、E11 抑郁、E12 幸福），K 值基于 10,266 人常模（|K|<3 正常、3–6 关注、≥6 预警），全链路可解释可教学；引擎独立打包为 `vibraimage_engine/`（pyproject.toml、独立测试与 NOTICE），可 `pip install` 单独复用；
2. **通用 GPU 适配层（`backend/gpu/`）**：将 MUSA（沐曦）/CUDA/CPU 自动探测、统一数组接口（to_gpu/to_cpu/histogram/rfft）与性能基准从业务中抽离为独立组件，任何 NumPy/SciPy 任务可复用；本平台经其实现端到端 14.06x 加速；
3. **通用 Prompt-based ReAct 框架（`backend/agents/framework/`）**：抽象出与业务解耦的 ReactAgent + ToolSpec 通用基座，通过 <tool_call>JSON</tool_call> 标签协议实现工具调用循环，适配不支持 function calling 的国产大模型（lingshu/moark）；心镜 5 个场景智能体基于该框架构建，框架本身可迁移到其他 LLM 场景；
4. **D-S 三模态融合**：`services/fusion.py` 实现基本概率分配（BPA）、Dempster 合成规则、未知焦点 Ω 与置信度折扣、冲突检测；提供 `/fusion/three-modal` 与 `/fusion/two-modal` 端点（后者用于消融对比）；
5. **实时双模态融合**：`backend/tools/multi_modal_fusion.py`（364 行）实现置信度自适应加权——面部熵置信度 + 前庭窗口方差置信度动态分配权重，输出融合 V/A、情绪标签与模态一致性复核标记；
6. **CAT 等价性**：7 题 vs 20 题对比，θ 相关 r=0.9181、高风险一致性 Kappa=0.7702、省题率 65%；
7. **虚拟被试教学闭环**：18 种剖面参数化生成，隐藏真值 + 自动批改，支持诊断算法校准（灵敏度/特异度/一致率批量评估）。

## 七、合规、安全与风险说明

### 7.1 开源及第三方许可合规

- 使用资源均已在《开源及第三方资源使用清单》如实披露（名称/版本/来源/许可证/使用方式/义务/自研边界）；
- **AGPL 说明**：Ultralytics YOLOv8 为 AGPL-3.0。当前默认人脸检测路径已切换为 OpenCV YuNet/Haar（Apache-2.0），YOLOv8 仅作为可选增强通过包依赖调用，权重不随仓库再分发；如需启用需用户自行下载并遵守 AGPL 义务——仓库与清单均如实披露。

### 7.2 数据、权利与隐私

- 平台无真实学生数据：全部演示与验证使用虚拟被试（is_virtual=True 严格隔离）或用户自备视频；不采集、不存储个人信息；
- 内置量表题库为公开标准化量表（Zung/Derogatis 等），常模数据来源已在文档标注。

### 7.3 AI 输出、知识产权与内容安全

- AIGC 报告含一致性校验（矛盾断言无法生成）、风险免责声明、多轮追问基于指标证据链；
- 未配置 LLM Key 时自动降级模板模式，保证 100% 可用；对 AI 生成代码与内容已逐项人工审核并记录于开发日志。

### 7.4 其他风险

- 情绪识别结果不构成医疗诊断，界面与报告均声明"辅助评估，不作临床诊断依据"；
- 合成数据验证的边界（需真实数据标定 IRT 参数、校准情绪映射）已在文档如实说明。
