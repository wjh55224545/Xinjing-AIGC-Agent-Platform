# 消融对照实验 E3：多模态情绪融合效果

- 数据：**合成被试 N=500**（is_synthetic=True，与真实样本隔离），seed=42，观测噪声 σ=0.45
- 判定目标：情绪三分类（负性 / 正性 / 中性）准确率
- 方法：证据理论融合（面部 VA / 前庭 VA / 量表 θ 三路独立带噪证据，含未知焦点置信折扣与冲突复核）

| 方法 | 准确率 |
|---|---|
| 单模态 · 面部 | 77.6% |
| 单模态 · 前庭 | 77.6% |
| 单模态 · 量表 | 79.0% |
| 双模态证据融合 · 面部+前庭 | 80.8% |
| 双模态证据融合 · 面部+量表 | 81.2% |
| 双模态证据融合 · 前庭+量表 | 83.6% |
| 三模态证据融合 · 面部+前庭+量表 | 81.4% |
| 旧方法 · 固定权重(0.6面部+0.4前庭) | 79.6% |

## 结论

- 单模态最佳 **79.0%** → 双模态证据融合最佳 **83.6%** → 三模态证据融合 **81.4%**：
  **多模态融合优于单模态**（各模态独立带噪，证据汇聚纠正彼此误差）。
- 旧固定权重融合 **79.6%** → 三模态证据融合 **81.4%**：
  升级为证据理论融合后提升 **+1.8%**，且新增旧方法不具备的
  不确定性（未知焦点）、冲突系数与复核机制能力。
- 三模态自动复核率 **43.4%**：当多模态主导结论分歧时，系统按证据质量
  采纳最可信来源并标记需复核（对应评分中的『分歧解释』）。
- ⚠️ 合成数据仅用于方法验证与教学演示，不冒充真实样本。
