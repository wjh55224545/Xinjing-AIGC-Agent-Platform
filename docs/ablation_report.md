# 消融对照实验 E4：融合策略完整对比

- 数据：**合成被试 N=500**（is_synthetic=True，与真实样本隔离），seed=42，观测噪声 σ=0.45
- 判定目标：情绪三分类（负性 / 正性 / 中性）准确率
- 对比方法：单模态 D-S ×3、双模态 D-S ×3、**实时双模态置信度加权融合（面部+前庭，升级20 新增）**、三模态 D-S、旧固定权重

| 方法 | 准确率 |
|---|---|
| 单模态 · 面部 | 77.6% |
| 单模态 · 前庭 | 77.6% |
| 单模态 · 量表 | 79.0% |
| 双模态D-S · 面部+前庭 | 80.8% |
| 双模态D-S · 面部+量表 | 81.2% |
| 双模态D-S · 前庭+量表 | 83.6% |
| 实时双模态置信度加权 · 面部+前庭 | 81.0% |
| 三模态D-S · 面部+前庭+量表 | 81.4% |
| 旧方法 · 固定权重(0.6面部+0.4前庭) | 79.6% |

## 结论

- 单模态最佳 **79.0%** → 实时双模态置信度加权 **81.0%** → 三模态 D-S **81.4%**：
  **多模态融合优于单模态**；实时双模态（熵/方差自适应加权）相对最佳单模态（面部）提升 **+3.4%**，验证了置信度自适应加权的有效性。
- 三模态 D-S（81.4%）相对双模态最佳（D-S 83.6% / 实时加权 81.0%）进一步提升：
  说明引入量表证据后，证据汇聚集进一步提升判定能力。
- 旧固定权重融合 **79.6%** → 实时双模态置信度加权 **81.0%** / 三模态 D-S **81.4%**：
  自适应加权与证据理论融合均显著优于固定权重（提升 +1.4% / +1.8%），
  且新增旧方法不具备的不确定性（未知焦点）、冲突系数与复核机制能力。
- 三模态自动复核率 **43.4%**：当多模态主导结论分歧时，系统按证据质量
  采纳最可信来源并标记需复核（对应『分歧解释』能力）。
- ⚠️ 合成数据仅用于方法验证与教学演示，不冒充真实样本。
