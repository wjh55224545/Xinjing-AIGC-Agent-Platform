## 附：问卷设计说明

### 设计原则
1. **教师视角**：所有问题均从教师教学需求出发，不涉及学生个人信息
2. **痛点导向**：先评估现有教学痛点，再评估功能需求，确保功能设计有真实痛点支撑
3. **量化+质化**：量化评分用于统计分析，开放题用于深度洞察
4. **可操作性**：问卷结果可直接转化为产品需求优先级和功能迭代计划

### 数据使用说明
- 问卷数据仅用于产品需求分析和功能优化，不用于任何商业用途
- 教师个人信息严格保密，统计分析时仅使用聚合数据
- 问卷结果将形成《教师需求分析报告》，作为产品迭代的重要依据

### 实施建议
1. **发放渠道**：心理学专业教师微信群、高校心理学系教研活动、心理学教学研讨会
2. **激励措施**：填写问卷的教师可优先获得平台试用资格和教学资源包
3. **样本量**：建议收集 30-50 份有效问卷，覆盖不同类型院校和教龄段
4. **后续跟进**：对填写联系方式的教师进行深度访谈，进一步挖掘需求细节
